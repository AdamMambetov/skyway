# SkyWay

SkyWay is a team-developed mobile survival game prototype built with Unreal Engine 5 for Android.

The player survives on a flying raft, gathers resources, processes materials, expands the raft, places functional devices, explores floating islands, and fights enemies.

* resource gathering and processing;

## Repository Structure

* `Source/Skyway` — C++ runtime module, character and AI code, project settings, and building-related components;
* `Content` — Blueprint logic, UI, levels, gameplay assets, and other project content;
* `Config` — Unreal Engine and Android project configuration;
* `Skyway.uproject` — Unreal Engine project descriptor.

## Project Status

SkyWay was developed as a team project and reached a playable mobile prototype state. The repository is published as a portfolio project and demonstrates work completed during development.
